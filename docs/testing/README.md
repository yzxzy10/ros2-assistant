## 一分钟结论

```
假 ROS（A）：3 秒，挡 80% 的"跑不起来"，判断错的结论可信，判断对的不可信
真 ROS（B）：分钟级，唯一能盖章的终审，但容易因环境问题误判
混合（C）  ：A 前置 + B 终审，90% 任务 5 秒出结果，容器只承接 10-30%
```

## 三条必须记住的设计原则

1. **三态判定**：`pass / fail / unknown`。把"没观测到"判成 `fail`，会导致噪音爆炸、学生不信任工具。
2. **日志不是证据**：日志由被检查者产生，会被 `try/except: pass` 吞掉、会被写死的字符串骗过。判据必须是"该有的事件有没有发生"。
3. **假环境 ≠ 安全环境**：假 ROS 只替换 `rclpy`，`os.remove`、`open`、`socket` 全部照常可用。隔离成本一分都省不掉。
